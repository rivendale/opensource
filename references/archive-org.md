# Reference: archive.org

A link-only reference page. No game files, manuals, magazines or assets are mirrored here.

Start with manuals and shareware for reference and learning. Check the individual item's terms before redistributing it: a collection listing is not a license. Commercial games are linked for preservation, never re-hosted; play from a copy you own. These collections do not grant rights to game art, audio or data.

Collection counts were read from Internet Archive's public search API on 2026-10-06 and may change.
