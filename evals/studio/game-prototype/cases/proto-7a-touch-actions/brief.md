Make a small browser game for phones, a coin catcher, that is playable with touch alone. The player slides left and right and jumps. Serve it as a static site: the page is `index.html` in the project root. The play surface is the element `#play`. The core-loop actions are `left`, `right` and `jump`. Each time one happens, append its name to the `data-action-log` attribute of `<body>`, separated by spaces (for example `left right jump`). Each action needs a control a player can touch: give it a `data-control` attribute equal to the action's name (or an accessible name equal to it). Keyboard play is welcome too. It will be tested on an Android Chrome phone profile in portrait and landscape and on a tablet, with touch events only.

Project layout (the same in every brief): the project root is the game. Code is in `src/` and `scripts/`, third-party credits in `THIRD_PARTY.md` (with the licenses' text kept), assets that
enter the build in `assets/` with a row each in `assets/MANIFEST.json` (see `skills/studio/manifest.schema.json`). Inputs are in `inputs/` and are read-only. Checks run `node` in a copy of
the project with no network.
